# PORTÕES

Pontos controlados de entrada e saída.

Um portão deve identificar origem e destino, verificar permissão, registrar passagem, encaminhar, acompanhar retorno e impedir ou colocar em análise aquilo que não possui autorização.

O padrão poderá ser usado para usuários, módulos, solicitações, dados, código, operações e comunicação. Portão é uma responsabilidade arquitetural, não necessariamente uma tela.
