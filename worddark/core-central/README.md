# CORE CENTRAL

Responsável pela coordenação global.

- mantém visão geral do mundo;
- recebe e distribui solicitações;
- acompanha o estado das áreas;
- identifica dependências;
- coordena respostas a problemas;
- solicita ações de executores;
- recebe resultados;
- respeita permissões e autorizações.

Não é o executor universal e não substitui a administração local.
