# Cidade de Compras — UI V1

Interface inicial da cidade, separada do core operacional.

## Princípios
- Portão → painel limpo → setor → detalhes.
- Uma interface por responsabilidade.
- Comunicação multicanal.
- Marketing e Dark Factory aparecem como serviços conectados, não como setores internos da fábrica.
- Esta UI não altera os contratos do core.

## Estrutura
- index.html — entrada/painel e área de setor
- styles.css — apresentação
- app.js — navegação e dados de interface

## Próxima evolução
Conectar cada tela aos contratos reais da cidade sem transformar o painel em um dashboard gigante.
