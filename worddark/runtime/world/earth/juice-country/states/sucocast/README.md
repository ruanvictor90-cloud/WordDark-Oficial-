# SucoCast

SucoCast é o primeiro estado/canal de referência do Juice Country.

## Papel

Canal geral de conteúdo variado, utilizado para testar a estrutura comum dos estados e a comunicação com a Dark Factory.

## Estrutura inicial

- Identidade do estado
- Setores / bairros
- Catálogo de operações
- Solicitações
- Resultados
- Registros locais

## Limite desta etapa

Este documento estabelece a estrutura. Ainda não automatiza pesquisa de tendências, edição, publicação nem conexão com plataformas externas.

## Objetivo de validação

Demonstrar que o SucoCast pode criar uma solicitação identificada, encaminhá-la pela interface definida, receber um resultado e manter rastreabilidade sem acessar diretamente o núcleo da Dark Factory.
