# Setores / bairros

Os setores são divisões internas de cada estado. Eles organizam responsabilidades sem transformar cada função em um sistema independente desnecessário.

## Modelo inicial de setor

- Identificador
- Nome visível
- Estado ao qual pertence
- Responsabilidade
- Operações permitidas
- Recursos utilizados
- Solicitações que pode enviar
- Estado operacional
- Registro de eventos

## Regra

Os setores começam como divisões organizacionais documentadas. Só viram módulos de código quando houver uma necessidade concreta e uma interface bem definida.
