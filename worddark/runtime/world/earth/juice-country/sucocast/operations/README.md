# SucoCast — Operações

Operação é a menor unidade funcional planejada dentro de um setor.

Uma operação deve evoluir de:

```
REGISTRADA
↓
TESTE
↓
VALIDADA
↓
ATIVA
```

A implementação deve manter rastreabilidade de identidade, solicitação, autorização, execução e resultado.

As operações ainda são apenas registradas no núcleo do Estado; não são automações completas nesta etapa.
