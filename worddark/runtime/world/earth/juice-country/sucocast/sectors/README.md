# SucoCast — Setores

Cada setor é uma área funcional independente do Estado.

Um setor organiza suas próprias operações, mas não altera a autorização central da WordDark nem executa diretamente tarefas pertencentes à Dark Factory.

## Estrutura

```
Setor
├── identidade
├── status
└── operações
```

Os setores atuais estão registrados em `../state.js`.
