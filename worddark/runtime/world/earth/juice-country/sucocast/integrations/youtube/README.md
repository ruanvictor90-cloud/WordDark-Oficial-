# YouTube — Adaptador SucoCast

Esta pasta reserva a integração do SucoCast com o YouTube.

Capacidades planejadas e separadas:

- youtube.read
- youtube.upload
- youtube.publish

O núcleo não conhece detalhes da API do YouTube. O adaptador traduz a operação do WordDark para a plataforma.

A implementação atual é somente de contrato/teste. Nenhum token real é armazenado ou enviado pelo GitHub Pages.
