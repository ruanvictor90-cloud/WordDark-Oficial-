Estruturas dinâmicas

Nenhuma estrutura de negócio nasce por legado.

A Terra não depende de País Suco, SucoCast ou qualquer outra estrutura histórica para funcionar. Identidades, grupos, operações e canais só aparecem quando uma necessidade real os cria. Referências antigas podem existir no código como material histórico, mas não são carregadas como estruturas ativas.

Pendência legada

Terra segue pela estrutura oficial dinâmica.

A ligação oficial da Terra usa País → Estado → Cidade → Bairro, com portão, necessidade, operação, resultado e memória. Não há necessidade de reativar estruturas legadas para operar o modelo atual.
