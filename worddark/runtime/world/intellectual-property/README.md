# Propriedade Intelectual — WordDark\n\nA PI é uma camada transversal do WordDark que acompanha o projeto dentro e fora do mundo: proveniência, titularidade declarada, versões, evidências, licenças, identidades externas e registros oficiais.\n\n## O que cada ativo deve declarar\n\n- OWNER — titular/autoridade declarada.\n- CREATOR — criador.\n- SOURCE — origem.\n- RIGHTS_STATUS — situação conhecida dos direitos.\n- LICENSE — licença ou autorização.\n- EVIDENCE — evidências de existência e evolução.\n- HASH — impressão digital do arquivo/código quando aplicável.\n- EXTERNAL_IDENTITY — identidade externa, como conta de rede social.\n- EXTERNAL_REGISTRATION — registro oficial, quando existir.\n- CONTRACT — contrato, cessão ou licença relacionada.\n\n## Dentro e fora do mundo\n\n**Interno:** código, arquitetura, documentação, processos, métodos, identidade visual, experimentos, interfaces e conteúdos.\n\n**Externo:** marcas, domínios, contas, perfis, publicações, contratos, licenças e registros oficiais ligados ao WordDark no mundo real.\n\nUma identidade externa não vira propriedade automaticamente só porque foi cadastrada no WordDark.\n\n## Ciclo\n\nINTENÇÃO → CRIAÇÃO → REGISTRO → VALIDAÇÃO → CLASSIFICAÇÃO → PRESERVAÇÃO → PROTEÇÃO EXTERNA → USO → LICENCIAMENTO/TRANSFERÊNCIA → ARQUIVO\n\n## Estados\n\nDRAFT → RECORDED → VALIDATED → PROTECTED → PUBLISHED → ARCHIVED\n\nPROTECTED significa que existe uma medida de proteção identificada; não significa, sozinho, que houve registro governamental.\n\n## Proteção jurídica real\n\nA estrutura interna não substitui os instrumentos jurídicos adequados. Para o WordDark devemos separar: marca/nome (INPI), software (INPI), obras autorais relevantes (Biblioteca Nacional/EDA), domínios e contas, contratos/licenças e informações estratégicas/confidenciais.\n\nA autoridade superior permanece na Área ADM/Ruan. A remoção de arquivo temporário nunca deve apagar o histórico de PI.\n
