# 03 · Identidade

Setor responsável por transformar a marca e o briefing em um pacote de identidade reutilizável.

Fluxo:
IDENTIDADE → REGRAS → ATIVOS → PACOTE DE IDENTIDADE

Entrada:
- operationId
- brand
- audience
- brief
- content
- constraints
- toolPolicy

Saída:
- status
- operationId
- brand
- visualRules
- voiceRules
- assetSlots
- metadata
- learning

A execução atual é local/simulada. Ferramentas externas ou motores próprios entram posteriormente via Adapter.
