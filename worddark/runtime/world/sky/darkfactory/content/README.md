# Fábrica de Criação — DF-CONTENT-0.1

Primeira camada visual e contratual dos setores especializados da Dark Factory.

## Objetivo
Criar uma interface única para receber briefing, selecionar setores e futuramente acionar ferramentas externas, próprias ou híbridas através de adapters.

## Setores
1. Inteligência
2. Roteiro
3. Identidade
4. Imagem
5. Vídeo
6. Áudio
7. Testes
8. Controle
9. Aprendizado

## Regra
A fábrica produz e entrega resultado. A decisão de distribuição/publicação continua com o Estado/cliente.

## Próxima integração
Cada setor deverá ganhar um adapter/serviço próprio, sem acoplar o Core diretamente a uma plataforma externa.
