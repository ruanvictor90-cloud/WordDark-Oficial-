# Security

A segurança da Dark Factory será construída como uma camada própria, separada dos executores.

## Objetivo

Garantir que o crescimento do WordDark não transforme a expansão em acesso irrestrito.

## Camadas planejadas

1. Identidade
2. Autenticação
3. Autorização
4. Escopo
5. Registro de eventos
6. Auditoria
7. Bloqueio e interrupção

## Princípio

**Identidade → autorização → execução → auditoria.**

Um executor não deve receber poder apenas porque está registrado.

## Importante

A autorização atual do DF-0.3 é demonstrativa. Esta pasta prepara o terreno para a futura camada de segurança real.
