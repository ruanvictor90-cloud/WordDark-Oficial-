# GOVERNANÇA

Responsável pelas regras administrativas e decisões de alto nível.

Deve definir e manter regras gerais, registrar decisões, controlar autorizações de alto impacto, estabelecer responsabilidades e determinar quando uma mudança exige aprovação.

Uma solicitação deve poder ser classificada como: informação, ação permitida, ação que exige aprovação, ação bloqueada ou ação que precisa de análise.
