# REGISTRO E AUDITORIA

Responsável pela rastreabilidade das ações relevantes.

Deve permitir saber o que aconteceu, quando, de onde veio, quem ou qual módulo iniciou, qual regra foi aplicada, quem autorizou quando necessário, para onde foi encaminhado e qual resultado ocorreu.

Áreas podem manter registros locais; informações relevantes podem ser encaminhadas à memória central.
