# PERMISSÕES

Responsável pelo modelo de acesso e autorização.

A permissão deve considerar identidade, área, função, recurso, ação, contexto, risco e necessidade de aprovação.

Ter acesso a uma área não significa ter autorização para fazer tudo dentro dela. O modelo deve permitir permissões locais e centrais sem exigir que todas as áreas compartilhem a mesma estrutura interna.
