# DESENVOLVIMENTO E MUDANÇAS

Responsável pelo ciclo de criação e alteração do mundo.

FLUXO: IDEIA → ANÁLISE → DESENVOLVIMENTO → TESTE → VALIDAÇÃO → AUTORIZAÇÃO → MUNDO ATIVO → REGISTRO

Mudanças estruturais importantes não entram diretamente no mundo ativo. O desenvolvimento pode criar novas áreas, módulos e soluções, mas sua entrada no mundo ativo respeita autorização e rastreabilidade.
