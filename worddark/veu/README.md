# Véu — fronteira de acesso do WordDark

O Véu representa a fronteira entre a autoridade externa autorizada e o mundo operacional WordDark. O mundo não administra a raiz de autoridade que o governa.

## Regras
- WordDark coordena operações dentro do escopo autorizado.
- Nenhum módulo pode elevar a própria autoridade ou aprovar a própria ação sensível.
- darkHub é uma ferramenta independente de análise, governança e criação; não é raiz de autoridade nem setor operacional do WordDark.
- Perfis DEV e Público serão definidos com controles próprios antes de expor interfaces.
- A interface visual não concede autoridade. A autorização real deverá ser aplicada no backend quando os conectores forem habilitados.
