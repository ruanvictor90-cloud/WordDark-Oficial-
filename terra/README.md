# TERRA

Camada territorial e operacional do mundo.

Poderá conter cidades, ilhas, setores e outras unidades locais.

Cada área poderá possuir identidade, responsabilidade, Core Local, memória, segurança, permissões, portões e comunicação com estruturas centrais.

Core Local administra sua própria área dentro das regras do mundo; Core Central coordena o mundo.

Nenhuma cidade ou setor será criado apenas para preencher a árvore. Primeiro definiremos o modelo de Terra e a relação entre suas áreas e o restante do mundo.
