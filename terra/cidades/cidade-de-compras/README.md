# Cidade de Compras

Cidade operacional transplantada da base anterior do WordDark.

O código funcional está em worddark/runtime/world/cidade-compras/ nesta primeira etapa para preservar os caminhos internos e evitar uma migração estrutural prematura.

Posição conceitual na Terra:

País -> Estado -> Cidade -> Bairro

A Cidade de Compras representa a camada de operação da cidade. Ela continua independente do Dark Factory e solicita serviços pela infraestrutura do mundo.
