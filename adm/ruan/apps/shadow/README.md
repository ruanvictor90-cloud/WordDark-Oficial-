# Shadow

Aplicativo independente com arquitetura de interface alinhada ao Ruan: cabeçalho, sino de notificações, widget de informações e central de módulos.

Nesta etapa é apenas a base visual/estrutural. Nenhum modelo de IA, memória de conversas, credencial ou conexão externa foi ativado. O sino lê localmente os alertas do Pessoal na mesma origem.
